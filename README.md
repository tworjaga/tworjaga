# About Me

Developer focused on backend systems, automation, and infrastructure.

Started coding out of curiosity, mostly figuring things out by building stuff, breaking it, and seeing how it works. Over time, that turned into working with systems that connect hardware, networks, and services.

My interests sit at the intersection of:

- systems programming
- backend development
- embedded hardware
- infrastructure
- Cybersecurity
- automation
- Sigint

I prefer understanding how things work instead of blindly relying on abstractions.

- Understand before building
- Keep things simple
- Reliability over hype
- Build things that are easy to debug and maintain
